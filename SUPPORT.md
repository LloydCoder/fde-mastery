# Support

## Where to ask

| Request | Recommended route |
|---|---|
| Bug or reproducible defect | [Open a bug report](https://github.com/LloydCoder/fde-mastery/issues/new?template=bug_report.yml) |
| Feature proposal | [Open a feature request](https://github.com/LloydCoder/fde-mastery/issues/new?template=feature_request.yml) |
| Setup and usage questions | [GitHub Issues](https://github.com/LloydCoder/fde-mastery/issues) |
| Security vulnerability | Follow [SECURITY.md](./SECURITY.md); do not use public issues |
| Private project or partnership enquiry | hello@tinlance.com |

## Before requesting help

1. Read the [README](./README.md) and [documentation index](./docs/README.md).
2. Check [Getting started](./docs/GETTING-STARTED.md), [Configuration](./docs/CONFIGURATION.md) and [Deployment](./DEPLOYMENT.md).
3. Search existing issues for the same behavior.
4. Include the operating system, Python/Node version, exact command, expected result and actual result.
5. Remove credentials, customer data, internal hostnames and other sensitive details from logs.

FDE Mastery is maintained on a best-effort basis. Support requests do not create a service-level agreement or guarantee a response time.
