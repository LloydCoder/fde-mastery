# Pricing Calculator

The platform uses a simple usage model for planning; contract pricing can be customized per deployment.

## Formula

`monthly_estimate = platform_base + (agent_executions × execution_rate) + (managed_integrations × integration_rate)`

Reference planning values:

| Component | Planning rate |
|---|---:|
| Platform base | $499/month |
| Agent execution | $0.02/execution |
| Managed integration | $149/month |

Example: 50,000 executions and 3 managed integrations = `$499 + $1,000 + $447 = $1,946/month`.

These are planning assumptions, not a binding quote. Model-provider, infrastructure, support, compliance and SLA requirements can change the final contract price.
